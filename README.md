## 📌 Project Overview

**Money Mitra** is a full-stack web application designed as a next-generation anime-themed digital banking platform. It provides seamless financial management with a modern glassmorphism UI/UX, robust REST API backend, and real-world banking features like UPI transfers, loan management with automated EMI deductions, virtual credit cards, bill payments, and more.

> ⚠️ **Disclaimer:** This is an educational project and NOT a real bank. Do not enter real financial details.

## 🚀 Features

### 🔐 Authentication & Security
- JWT-based authentication with access & refresh tokens
- Strict 10-minute auto-logout for security
- Role-based access control (User / Admin)
- Automatic login upon registration
- Global rate limiting & Helmet.js security headers

### 💰 Core Banking
- Multi-account support per phone number
- Real-time balance tracking with transaction history
- Fund transfers (account-to-account, NEFT, RTGS, IMPS)
- Downloadable transaction statement PDFs with profile picture

### 📱 UPI System
- UPI ID generation & management
- Scan & Pay / Send by UPI ID
- UPI transaction history

### 💳 Credit Cards
- Virtual card generation with anime-themed designs
- Card freeze / unfreeze controls
- Real-time spend tracking

### 🏦 Loans & EMI
- Apply for personal loans with flexible tenures
- Admin loan approval → Auto-disburses to user's account
- **Automated EMI deductions** via daily cron job
- Insufficient balance notifications
- Loan status tracking (pending → disbursed → closed)

### 💡 Bill Payments
- Pay electricity, water, broadband, and more
- Bill history and receipt generation

### 👨‍💼 Admin Panel
- Full user management (view, edit, delete)
- Loan approval / rejection dashboard
- Transaction monitoring
- System-wide analytics

### 📄 Public Pages (No Login Required)
- **About Us** – Developer team showcase with clickable profile photos
- **Savings Account, Current Account, UPI Transfers, Personal Loans, Credit Cards** – Product info pages
- **Privacy Policy, Terms of Service, Cookie Policy, Security** – Legal pages
- **Blog, Press** – Company pages

### 🔔 Notifications
- Real-time in-app notifications
- EMI deduction alerts
- Transaction confirmations

## 🚀 Step-by-Step Setup After Git Clone

### Step 1 — Clone the Repository

```bash
git clone https://github.com/ankitdas37/Money-Mitra-Simple-Banking-System-Website.git
cd Money-Mitra-Simple-Banking-System-Website
```

---

### Step 2 — Set Up MySQL Database

```bash
mysql -u root -p
```

```sql
CREATE DATABASE money_mitra;
EXIT;
```

```bash
mysql -u root -p money_mitra < backend/database/schema.sql
```

Optional — seed demo data:
```bash
mysql -u root -p money_mitra < backend/database/seed.sql
```

---

### Step 3 — Configure Backend Environment

```bash
cd backend
copy .env.example .env
```

> On Mac/Linux: `cp .env.example .env`

Edit `.env` with your MySQL credentials:

```env
PORT=5000
NODE_ENV=development

DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=YOUR_MYSQL_PASSWORD
DB_NAME=money_mitra

JWT_SECRET=money_mitra_super_secret_jwt_key_2024
JWT_REFRESH_SECRET=money_mitra_refresh_secret_2024
JWT_EXPIRY=15m
JWT_REFRESH_EXPIRY=7d

FRONTEND_URL=http://localhost:5173
APP_NAME=Money Mitra
```

---

### Step 4 — Install & Start Backend

```bash
cd backend
npm install
npm run db:init
npm run dev
```

✅ Backend starts at: **http://localhost:5000**

---

### Step 5 — Install & Start Frontend

Open a **new terminal**:

```bash
cd frontend
npm install
npm run dev
```

✅ Frontend starts at: **http://localhost:5173**

---

### ✅ Both servers must be running simultaneously!

| Service | URL |
|---------|-----|
| Frontend | http://localhost:5173 |
| Backend | http://localhost:5000 |

|----------|-------------|---------|

## ❓ Troubleshooting

| Problem | Solution |
|---------|----------|
| Can't connect to MySQL | Ensure MySQL is running. Check password in `.env` |
| `npm install` fails | Use Node.js v18+. Delete `node_modules` & `package-lock.json`, retry |
| Blank page / API errors | Ensure backend is running on port 5000. Check `FRONTEND_URL` in `.env` |
| Port already in use | Change `PORT` in `.env` or use `npm run dev -- --port 5174` |
| MySQL command not found | Add MySQL to your system PATH or use MySQL Workbench GUI |
